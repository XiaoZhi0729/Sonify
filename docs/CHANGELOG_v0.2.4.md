# Sonify v0.2.4 更新日志

## 新增功能

- **人声分离**：可在线分离人声与伴奏，支持比例调节，切歌自动关闭
- **前往该歌曲专辑**：播放页更多菜单新增直达歌曲所属专辑
- **高潮起点标记**：进度条上标出歌曲高潮起点，可在设置中关闭
- **歌单页内搜索**：歌单详情页搜索按钮形变展开，就地过滤列表
- **长按呼出菜单**：长按按钮可展开下拉菜单，展开后可不停手滑选
- **主页预加载**：启动时预加载内容，带骨架屏扫光过渡

## 性能与体验优化

- 优化播放页进出动画性能（封面层与背景渲染路径调整）
- 优化播放页背景渲染方式（Ken Burns 改为 30fps 图层驱动，压暗烘焙常驻）
- 优化人声分离个别设备上的失效问题，下线「浮点音频输出」
- 优化在线歌单封面：按最新添加歌曲重建并落盘缓存
- 优化「添加至歌单」弹层的封面缓存复用
- 优化流量下的音源选择：自动改用本机已缓存的高音源
- 优化艺人页：底色动画落定后整页录制层改为 blit 上屏，倒影烘焙降峰
- 优化顶栏模糊性能，关闭液态玻璃时部分按钮的采样层级修复
- 优化播放页翻译按钮样式、设备显示位置、内容加载样式、玻璃组件样式
- 优化音质的选择逻辑
- 优化系统媒体（通知栏）歌词显示逻辑，不再依赖蓝牙连接
- 优化本地库列表性能（可见歌曲与艺人/专辑索引缓存）
- 优化下拉菜单动画与交互（关门时采样模糊后的顶栏表面，运动期摘掉昂贵装饰层）

## 功能修复

- 修复逐行歌词显示高度异常（行级 LRC 行结束时间回填下一行起点）
- 修复不同歌手歌词识别异常（报幕标签改用结构判据，串烧歌曲不再左右乱跳）
- 修复连点返回按钮页面消失
- 修复播放页小窗/分屏下控件消失（传输键被压成 0）
- 修复播放页控件带空点击层吞掉标题行与歌词区手势
- 修复横屏歌词顶部渐隐消失
- 修复歌词长句对半折行
- 修复歌词放置阶段崩溃（place is called on a deactivated node）
- 修复封面倾斜时圆角被切回直角
- 修复平板横屏分栏态底部「设备」块左缘未对齐控件带
- 修复音量条外缘未对齐进度条轨道线
- 修复艺人页数量行未水平居中
- 修复在线播放凭据恢复误判登录失效
- 修复已知崩溃（在线专辑首屏缓存毒化、歌单越界等）

## 其它

- 支持内嵌 A2 增强型 LRC（字级 `<mm:ss>` 尖括号标签）
- 新增下拉菜单生命周期测试与多项自动化测试覆盖
