# Sonify v0.1.1 更新帖

标题：Sonify v0.1.1：应用内更新、私人 FM 和在线歌单管理

Sonify v0.1.1 测试版已更新。一个仿 Apple Music 风格的开源 Android 音乐播放器，支持本地音乐与酷狗在线曲库，手机和平板均可使用。

这次更新：

- 新增应用内检查更新、下载进度和安装入口。安装一次新版后，后续可以直接在「设置 → 关于」检查更新。
- 新增每日推荐、私人 FM、在线艺人入口与歌手详情。
- 完善我的在线歌单创建、删除和歌曲管理。
- 优化歌曲平滑过渡，修复切歌、解析超时和部分列表越界问题。
- 统一玻璃弹窗、优化排序菜单与屏幕圆角适配。

支持 Android 6.0 及以上。从 v0.1.0 升级需要手动下载 APK 并覆盖安装一次；更新不会静默安装。仍是测试版，欢迎反馈设备型号和复现步骤。
