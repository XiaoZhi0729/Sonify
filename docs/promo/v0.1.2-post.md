# Sonify v0.1.2 更新帖

标题：Sonify v0.1.2：在线艺人页重做、播放页过渡与在线播放修复

Sonify v0.1.2 测试版已更新。一个仿 Apple Music 风格的开源 Android 音乐播放器，支持本地音乐与酷狗在线曲库，手机和平板均可使用。

这次更新：

- 重做在线艺人页：Apple Music 式布局，热门歌曲和全部专辑有独立二级页，合辑里的每位歌手都能单独点进去。
- 在线收藏艺人接入酷狗「我关注的歌手」，收藏跟着账号走。
- 播放页歌手名可以直接点进艺人主页；专辑、歌词、播放列表之间的切换换成更顺滑的动画，不再闪。
- 修复在线拖动进度条会有一次暂停的问题，并给在线音频加了磁盘缓存，回退进度不用重新联网拉取。
- 修复逐字歌词竖排错位，逐字高亮保留。
- 搜索页新增歌手分类，专辑、歌单、歌词支持滚动分页。
- 顺手修了系统返回手势串栈、歌词控件收起后下半屏点不动的问题。

支持 Android 6.0 及以上。已装 v0.1.1 及以上可在「设置 → 关于」检查更新；更新不会静默安装。仍是测试版，欢迎反馈设备型号和复现步骤。
