# Sonify v0.2.6 更新日志

> 紧接 v0.2.5（含 v0.2.5-v2 预览版改动），重点围绕 **液态玻璃视觉升级、播放页与横屏体验完善、性能深度优化** 与 **云更新通道增强**。

## 新增功能

### 液态玻璃与视觉
- **iOS 27 双层立体玻璃描边**：复刻 iOS 27 玻璃边缘高光与倒角效果，并在深色与浅色模式下统一应用至主壳体、底栏、顶栏按钮、下拉菜单、音乐画廊及玻璃调节面板
- **底栏自定义与外部音频打开**：支持底栏布局自定义及从外部文件/应用直接打开音频播放
- **艺人页横屏 Hero 布局统一**：艺人详情页横屏采用二维镜像拉伸模糊 Hero 与左右分栏内容布局，并优化最新专辑卡片与歌曲分页展示

### 播放页与音乐画廊
- **横屏歌词页悬浮控制**：平板/横屏播放页进入歌词界面时，右上角新增向下展开的人声分离药丸与翻译切换按钮
- **音乐画廊点击切歌**：支持直接点击两侧露出的封面跳转并播放对应曲目
- **歌词 HDR 高光实时调节**：修复歌词 HDR 高光实时开关与强度调节，并接入设置页实时预览

### 云更新与通道
- **Gitee 国内加速与兜底**：新增 Gitee 镜像源优先下载与 GitHub 自动兜底，并兼容 `raw.giteeusercontent.com` 重定向
- **预览版更新通道**：设置中支持开启/关闭接收预览版更新

## 性能与体验优化

- **播放页展开/收起流畅度优化**：消除展开与收起过程中的 120Hz 全树重组与冗余离屏绘制，并将控件动画下沉至渲染层
- **后台与暂停态零空转**：消除播放页收起态与暂停态下的 CPU/GPU 后台空转，降低功耗与发热
- **主线程与列表渲染优化**：减少主线程 IPC 调用并优化列表渲染开销
- **HDR 歌词裁剪优化**：滑行 HDR 歌词改用无离屏层的控制带上方裁剪，避免额外离屏开销
- **状态栏自动隐藏与取色动画**：完善全屏/播放页状态栏自动隐藏逻辑，优化封面取色与过渡动画

## 功能修复

- 修复关闭/切换歌词 HDR 高光时设置预览与实际渲染不同步的问题
- 修复 Gitee 清单地址发生 `raw.giteeusercontent.com` 重定向时更新检查失败的问题
- 修复播放页与艺人页多处控件细节及音量滑块交互问题
