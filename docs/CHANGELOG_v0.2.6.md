# Sonify v0.2.6 更新日志

> 汇总 **v0.2.5 至 v0.2.6**（含 **v0.2.5-v2** 预览版）期间的全部新增功能、性能与体验优化及问题修复。

## 新增功能

### 个性化与主题外观
- **自定义主题色**：新增主题色设置，内置 11 种预设色彩（红、粉、橙、黄、绿、薄荷绿、青绿、天青、蓝、靛蓝、紫），并支持打开自定义取色器（提供**网格 / 色谱 / 滑块**三种模式及 RGB、饱和度/彩度/明度与不透明度调节）
- **自定义底栏**：支持在设置中拖动调整底栏标签顺序、隐藏或恢复标签（至少保留 2 项）、自定义冷启动默认页面、实时预览效果及一键恢复默认
- **iOS 27 双层立体玻璃描边**：复刻 iOS 27 玻璃边缘高光与倒角质感，并在深色与浅色模式下统一应用至主壳体、底栏、顶栏按钮、下拉菜单、音乐画廊及玻璃调节面板
- **播放页自动隐藏状态栏**：支持在播放页展开期间隐藏系统状态栏，使背景与封面铺满至屏幕顶端，同时保持页面布局位置稳定不跳动

### 播放与音频能力
- **智能过渡（Crossfade）**：过渡模式新增「**智能过渡**」（保留「平滑过渡」），可分析歌曲首尾节奏、能量与静音尾段，自动决定切入时机、响度平衡与下潜混响融合，并支持调节「音色与空间混响」强度
- **ExoPlayer 解码器策略切换**：新增 `Auto` / `FFmpeg` / `System` 三档解码策略；`Auto` 对普通格式优先设备硬解，FLAC 无损自动走 FFmpeg 软解以避免部分设备卡死
- **外部音频直接打开**：支持从系统文件管理器或其他第三方应用直接通过 Sonify 打开并播放音频文件
- **人声分离增强**：优化人声分离处理管线与状态管理，并在横屏/平板歌词页提供向下展开的悬浮控制

### 音乐画廊、播放页与艺人页
- **画廊独立设置与点击切歌**：音乐画廊新增独立设置页（可跟随「音乐播放页」，或单独选用静态背景 / 慢速推拉漂移 / 流体网格），支持上一首/下一首控制及直接点击两侧露出的封面跳转播放
- **横屏歌词页悬浮控制**：平板/横屏播放页进入歌词界面时，右上角新增向下展开的人声分离药丸与翻译切换按钮
- **艺人页横屏重构与最新发行**：艺人详情页新增「最新发行」卡片展示；横屏统一为二维镜像拉伸模糊 Hero 与左右分栏内容布局，并优化歌曲分页展示
- **歌词 HDR 高光实时调节**：修复并完善歌词 HDR 高光实时开关与强度调节，接入设置页实时预览

### 云更新与通道（含 v0.2.5-v2）
- **Gitee 国内加速与兜底**：新增 Gitee 镜像源优先下载与 GitHub 自动兜底，并兼容 `raw.giteeusercontent.com` 重定向
- **预览版更新通道**：设置中新增「接收预览版更新」开关，可按需接收正式版之间的 V1/V2 预览更新

## 性能与体验优化

- **播放页展开/收起流畅度优化**：消除展开与收起过程中的 120Hz 全树重组与冗余离屏绘制，并将控件动画下沉至渲染层
- **后台与暂停态零空转**：消除播放页收起态与暂停态下的 CPU/GPU 后台空转，降低功耗与发热
- **主线程与列表渲染优化**：减少主线程 IPC 调用并优化列表渲染开销，优化封面取色、底栏 Tab 切换遮罩同步及阻尼拖拽手感
- **HDR 歌词裁剪优化**：滑行 HDR 歌词改用无离屏层的控制带上方裁剪，避免额外离屏绘制开销

## 功能修复

- 修复关闭/切换歌词 HDR 高光时设置预览与实际渲染不同步的问题
- 修复 Gitee 清单地址发生 `raw.giteeusercontent.com` 重定向时更新检查失败的问题
- 修复播放页、音量滑块及艺人页多处控件细节与交互问题
- 补充外部音频 Intent、解码器选择、底栏布局、人声分离、阻尼拖拽及取色/歌词渲染键等单元测试
