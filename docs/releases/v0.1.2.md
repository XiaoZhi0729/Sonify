# Sonify v0.1.2

Sonify v0.1.2 测试版，支持 Android 6.0 及以上，安装包包含 arm64-v8a 与 armeabi-v7a。

## 本次更新

- 重做在线艺人体系：艺人详情页改为 Apple Music 式布局，新增热门歌曲与全部专辑二级页，合辑的多位作者可逐个点击进入对应艺人页。
- 在线收藏艺人接入酷狗「我关注的歌手」，收藏状态在应用与账号间同步。
- 播放页歌手名可点击跳转艺人主页；专辑、歌词与播放列表之间的切换过渡重做为零位移交叉淡化配合元素级形变动画，切换不再闪烁。
- 修复在线音乐拖动进度条时先暂停再继续播放的问题，并为在线音频加入磁盘字节缓存，回退进度不再重新从网络拉取。
- 修复逐字时间戳歌词在竖排下错位，逐字卡拉 OK 高亮保留。
- 搜索页新增歌手分类，专辑、歌单与歌词列表支持滚动分页加载。
- 优化玻璃材质与动效：顶栏渐进模糊、底栏与迷你播放条的取色，以及播放器外壳展开收回时的材质与遮罩同步。
- 修复系统返回手势在多标签页下串栈，以及歌词控件收起后下半屏点击与滚动失效的问题。
- 私人 FM 改为连续补货，减少播放过程中的停顿。
- 关于页新增开发者模式入口。

## 安装与升级

下载附件 `Sonify-v0.1.2.apk` 后覆盖安装。包名为 `com.sonify.music`，内部版本编号为 `3`。

已安装 v0.1.1 及以上的版本可在「设置 → 关于 → 检查更新」中获取本版本。应用不会在检查成功后自动下载，安装仍需用户确认。

本版本沿用 v0.1.0 起的 Android Debug 签名以保持覆盖安装兼容性。它不是正式生产签名方案；签名迁移会另行说明，不能直接更换密钥并保证无损覆盖安装。

应用内更新清单与 APK 均托管于 GitHub；部分网络可能无法直连，检查或下载失败时可使用弹窗中的发行页面手动下载。Android 8.0 及以上安装时需要允许 Sonify 安装应用。
