# Sonify v0.1.1

Sonify v0.1.1 测试版，支持 Android 6.0 及以上，安装包包含 arm64-v8a 与 armeabi-v7a。

## 本次更新

- 新增应用内更新：关于页手动检查、前台自动检查、下载进度与取消、系统安装授权和安装入口。
- 更新包下载后校验大小、SHA-256、包名、版本与签名身份；不会自动下载或静默安装。
- 新增每日推荐、私人 FM、在线艺人入口与歌手详情，完善 FM 的连续补货。
- 支持我的在线歌单创建、删除和歌曲管理，修复新建歌单及修改后刷新问题。
- 重做歌曲平滑过渡的播放器交接，修复切歌取消污染失败缓存，并为解析链加入全局超时。
- 修复搜索、推荐和列表的状态/列表键不同步导致的越界问题。
- 统一玻璃对话框、优化歌曲排序菜单，并调整屏幕圆角适配与校准入口。

## 安装与升级

下载附件 `Sonify-v0.1.1.apk` 后覆盖安装。包名为 `com.sonify.music`，内部版本编号为 `2`。

v0.1.0 没有应用内更新入口，需要手动覆盖安装这一次。v0.1.1 起可在「设置 → 关于 → 检查更新」获取后续版本。应用不会在检查成功后自动下载，安装仍需用户确认。

本版本沿用 v0.1.0 的历史 Android Debug 签名以保持覆盖安装兼容性。它不是正式生产签名方案；签名迁移会另行说明，不能直接更换密钥并保证无损覆盖安装。

应用内更新清单与 APK 均托管于 GitHub；部分网络可能无法直连，检查或下载失败时可使用弹窗中的发行页面手动下载。Android 8.0 及以上安装时需要允许 Sonify 安装应用。
