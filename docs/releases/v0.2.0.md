# Sonify v0.2.0

Sonify v0.2.0 测试版，支持 Android 6.0 及以上，安装包包含 arm64-v8a 与 armeabi-v7a。

## 本次更新

### 歌词

- 歌词引擎改用新的第三方库重建：整页卡拉 OK 渲染，逐字高亮。原有的辉光、HDR 泛光、景深模糊与字号缩放选项全部保留。
- 修复字重、字号、行平衡改完不立即生效的问题。

### 播放页

- 新增评论区：可查看、点赞、回复与删除当前歌曲的评论。
- 新增全屏静态封面选项：封面铺满播放页，且不再随播放状态缩放。
- 新增车载蓝牙歌词（默认关闭）：连接蓝牙音频设备时，把当前歌词行写入媒体会话标题，供车机显示。
- 歌曲行新增三竖点菜单：添加至歌单、喜爱、下一首、不感兴趣、前往艺人。
- 统一封面渲染为单层，消除关闭播放页时的双层封面与页面切换抽动。

### 听歌识曲

- 新增听歌识曲：点击搜索框旁的麦克风，识别周围正在播放的歌曲。

### 主页与详情页

- 主页支持自定义：可隐藏板块、拖动排序，改动在点「完成并保存」后生效。
- 在线专辑页与歌单页改用封面提取色作背景，文字颜色按可读性自动择优。
- 艺人页背景改为整体渐入，修复倒影带尾与提取色的硬分割。
- 在线专辑页不再为每首歌重复显示封面，改用行首序号。
- 在线歌单隐藏空的系统「默认收藏」歌单。

### 设置与其它

- 新增「玻璃效果」设置页：玻璃控件的模糊强度可在 0%~200% 之间调节。顶栏渐进模糊等背景类效果不受影响。
- 音频与图片缓存上限可调，新增缓存明细页查看各项占用。
- 关于页更新横幅与贡献者列表，开发者模式新增头像。

### 修复

- 修复列表中可播放歌曲被误置灰的问题（会员/付费歌取不到播放地址时的误判）。
- 修复详情页「播放」按钮未关闭随机播放的问题。
- 修复播放页翻译按钮图标。
- 修复「喜爱」Tab 下点歌手名崩溃等此前版本遗留问题。

## 安装与升级

下载附件 `Sonify-v0.2.0.apk` 后覆盖安装。包名为 `com.sonify.music`，内部版本编号为 `7`。

已安装 v0.1.1 及以上的版本可在「设置 → 关于 → 检查更新」中获取本版本。应用不会在检查成功后自动下载，安装仍需用户确认。

本版本沿用 v0.1.0 起的 Android Debug 签名以保持覆盖安装兼容性。它不是正式生产签名方案；签名迁移会另行说明，不能直接更换密钥并保证无损覆盖安装。

应用内更新清单与 APK 均托管于 GitHub；部分网络可能无法直连，检查或下载失败时可使用弹窗中的发行页面手动下载。Android 8.0 及以上安装时需要允许 Sonify 安装应用。
