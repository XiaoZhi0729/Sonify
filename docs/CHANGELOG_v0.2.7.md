# Sonify v0.2.7 更新日志

## 新增功能

### 搜索与发现
- 搜索页新增「编辑精选专区」：专区列表、专区详情（歌曲 / 歌单 / 专辑 / 歌手聚合），支持加载失败重试与空状态提示。
- 首页新增 VIP 专属推荐与小众宝藏，支持首页布局自定义与骨架屏优化。

### 资料库
- 资料库板块支持自定义（拖拽排序与显隐）。
- 歌曲行新增 Apple Music 风格左右滑动操作，并配有 Mochi 顶部胶囊提示。

### 播放页与歌词
- 播放页歌名与歌手过长时改用跑马灯滚动，并带边缘渐隐。
- 歌词支持对唱分栏开关，优化合唱与角色标签对齐。
- 歌词库升级至 patched25（含 HDR 提亮修正）。
- 新增渐进模糊交叉淡入追踪。

### 支持与设置
- 新增「捐赠与支持」页面，含赞赏记录与微信收款码保存/跳转。

## 性能与体验优化
- 宽屏 / 平板首页歌曲列自适应多列，搜索专辑/歌单结果网格自适应。
- 音乐画廊热路径优化，减少每帧分配与重组。
- 深色模式玻璃增加厚度感；渐进模糊参数调优。
- 歌词字体优先使用系统可变字体，实现真·无极字重。
- 封面效果、取色与过渡动效优化；OverScroll 手感调整。
- 艺人页横屏封面高度与分区标题间距对齐。

## 修复
- 更新下载：允许 Gitee `attach_files` 跳转，修复国内镜像下载慢、回退 GitHub 的问题。
- 修复搜索最佳结果大卡缺少「加入歌单」入口。
- 补充歌词几何等单元测试。
