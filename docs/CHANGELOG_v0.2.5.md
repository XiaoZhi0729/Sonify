# Sonify v0.2.5 更新日志

## 新增功能

- **专辑动态封面**：支持在线歌曲的动态封面探测与播放，手机流量下可单独开关
- **桌面小组件**：新增 4×2、4×1、2×2 三种尺寸，支持播放模式切换与最近播放队列架
- **多语言字母索引**：资料库接入字母索引栏与全场景排序菜单
- **歌词自定义字体**：歌词页可选择自定义字体渲染
- **首次启动引导**：全新的四屏引导流程，含玻璃质感交互与实时预览

## 性能与体验优化

- 优化 120Hz 滚动帧率与液态玻璃离屏渲染管线
- 优化封面解码尺寸：按实际显示尺寸取图，解决大卡片与网格中封面发虚
- 优化播放页切歌过渡：封面与背景共用同一条过渡时间轴，不再硬切
- 优化艺人页 hero 渐进模糊面积与路径
- 优化设置页胶囊组件几何与 LiquidSwitch 采样
- 优化浅色模式下底栏与播放器外壳的白色渐变带
- 优化底栏 Tab 玻璃指示器跟随「玻璃效果调节」模糊强度
- 通知栏播放模式整合为四态按键，左侧改为爱心收藏

## 功能修复

- 修复首次启动先闪主页、退出淡出闪回上一页及主页浮现动画衔接问题
- 修复液态玻璃与混色模糊切换时滑块不即时更新
- 修复网格样式下拉菜单点选错位（写入查表、读取不查表）
- 修复冷启动后状态栏图标不反色
- 修复歌词关闭扩展亮度直绘后逐字扫色异常
- 修复在线播放 commitReload 后未自动继续播放

## 其它

- 播放页设置独立成页，新增 Pear Wall 流体网格背景选项
- 补充单元测试：动态封面解析、歌词渲染键、阻尼拖拽动画、歌词设置
