# Sonify v0.2.5 更新日志

> 距 v0.2.4（11-01）约两周，累计 269 个文件改动、约 3.3 万行新增。

## 新增功能

### 专辑动态封面
- 播放页支持在线歌曲的动态封面（`/album/dycover` 探测 + 缓存 + 视频叠层）
- 可单独开关，手机流量下可选择是否加载

### 首次启动引导
- 全新四屏引导流程（欢迎 / 登录 / 能力介绍 / 就绪）
- 玻璃质感卡片与实时预览，选开关当场看到效果
- 手机号验证码登录、账号二维码扫码两条路径
- 首次启动不再先闪主页，退出无闪回

### 桌面小组件
- 新增 4×2 播放器、4×1 紧凑条、2×2 卡片三种尺寸
- 支持播放模式切换、最近播放队列架、封面取色
- 中英文排版适配，长标题跑马灯

### 音乐画廊
- 原「私人电台」升级为「音乐画廊」，四槽位环形轮转
- 提取色渐变底 + 玻璃遮罩，封面随歌浮动

### 播放页与视觉
- **Pear Wall 流体网格背景**（3 张封面反向慢旋 + 6-pass 模糊 + 网格形变），播放页设置独立成页
- 封面与背景共用一条切歌过渡时间轴，不再硬切
- 顶栏/底栏/播放器外壳按封面取色铺柔和渐变
- 艺人页 hero 渐进模糊面积加大、路径拉长
- 液态玻璃新增「玻璃效果调节」全局模糊强度倍率

### 歌词
- 支持自定义字体渲染
- HDR 歌词高光尝试与逐字扫色修复
- 新增「高潮起点标记」（进度条上标出副歌起点）

### 资料库与搜索
- 资料库接入 **MochiIndexBar 多语言字母索引** + 全场景排序菜单
- 搜索页按 Apple Music 结构重做：最佳结果卡 + 歌曲/艺人/专辑分区
- 歌单详情页页内搜索，圆钮原地形变展开

### 其它
- 通知栏播放模式整合为四态按键，左侧改为爱心收藏
- 播放页「前往该歌曲专辑」
- 人声分离（MSS 模型移植，比例可调）

## 性能与体验优化

- 优化 120Hz 滚动帧率与液态玻璃离屏渲染管线
- 优化封面解码：按实际显示尺寸取图，解决大卡片/网格封面发虚
- 优化艺人页倒影烘焙降峰、内存缓存按字节封顶
- 优化私人电台玻璃：采样源补底色层，修复「下半截虚」
- 优化浅色模式底栏与播放器外壳的白色渐变带
- 优化设置页胶囊组件几何与 LiquidSwitch 采样
- 优化底栏 Tab 玻璃指示器跟随模糊强度
- 优化播放页进出场性能，运动期摘掉昂贵装饰层
- 开屏改用 Logo 轮廓作窗口，蓄力后 spring 铺满

## 功能修复

- 修复首次启动先闪主页、退出淡出闪回上一页
- 修复液态玻璃与混色模糊切换时滑块不即时更新
- 修复网格样式下拉菜单点选错位（写查表、读不查表）
- 修复冷启动后状态栏图标不反色
- 修复封面倾斜时圆角被切回直角
- 修复歌词关闭扩展亮度直绘后逐字扫色异常
- 修复歌词长句对半折行、激活行偏上
- 修复横屏歌词顶部渐隐消失、底部按钮间距不均
- 修复平板横屏翻译按钮点不动、控件消失
- 修复返回按钮连点退到纯色页
- 修复小窗/分屏下传输键被压成 0
- 修复账号风控导致无法播放
- 修复收藏歌单歌曲顺序错误
- 修复在线播放 commitReload 后未自动继续播放
- 修复个别设备人声分离整体失效

## 其它

- 新增单元测试：动态封面解析、歌词渲染键、阻尼拖拽动画、歌词设置、Mochi 索引栏、小组件状态、画廊几何等
- 内置 backdrop / capsule 库源码入库
