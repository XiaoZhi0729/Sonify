                            pinch.vert,material.frag}

Modified for Sonify:
- Render host replaced. Upstream draws into an AndroidEmbeddedExternalSurface, which is a
  separate SurfaceFlinger layer and therefore invisible to Compose layer recording. Sonify's
  liquid-glass panels sample the player backdrop through Modifier.layerBackdrop, so the host
  is a TextureView instead (PearMeshTextureView.kt); the EGL renderer itself is unchanged.
- Removed the moru ("long rain glass") post-processing pass and its five normal/light
  lookup textures, which upstream defaults to off. material.frag keeps only the modes that
  the ported pipeline actually binds.
- Removed the frame-capture/export path and the on-screen render diagnostics.
- Removed the four-lane audio visualisation. Its only visual effect upstream was a shared
  scale factor applied to the rotating artwork group, so the port renders with a constant
  scale of 1. Sonify drives the waveform elsewhere and this mode ships without it.
- `behindLyricsProgress` is pinned to 1f. That is upstream's own default for the wallpaper
  and selects the warped material, which is the flowing look this mode is meant to provide.
- Bundled as a user-selectable second background mode rather than a live wallpaper service;
  presets are chosen by screen orientation only, with no randomise-on-screen-on.
